### Hi, I'm Moshe 👋

I like building things close to the metal: no engines, no frameworks, no runtime. Just the CPU, the OS and a lot of registers.

🧱 **Currently building [MineAssembly](https://github.com/BaramiDev/MineAssembly)**: a complete voxel sandbox game written in **100% hand-written x86-64 assembly**.
No C runtime, no game engine, no asset files. Every texture, sound and note of music is generated by the code at startup, and the whole game ships as a single `.exe`.

**What's inside:**
- Infinite procedural worlds: biomes, mountains, rivers, caves, ores, trees
- Smooth lighting and ambient occlusion, a day/night cycle, clouds, rain and snow
- Survival and creative modes, crafting, furnaces, chests, mobs, TNT, flowing water and lava
- Multithreaded chunk generation, OpenGL rendering, a synthesized sound engine and generative music
